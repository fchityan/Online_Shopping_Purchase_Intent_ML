# Model Assurance & Experiment Evidence

This folder preserves historical MLflow experiment-tracking evidence, including model comparisons, recorded metrics, parameters, and supporting artefacts.

- [MLflow experiment evidence](mlflow-experiment-evidence/)
- [Project evaluation summary](../outputs/summary.json)
- [Model validation and threshold assessment](../docs/ai-enablement/ai-readiness-and-model-governance-assessment.md)

**Evidence boundary:** The reported model metrics apply to the evaluation dataset; these files are not evidence of actual campaign uplift, business-user acceptance, or live production deployment.

The existing `src/` package, `tests/` suite, and `outputs/` runtime path remain unchanged so training and scoring code are not disrupted.
